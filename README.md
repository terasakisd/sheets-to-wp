# GS Dynamic Content - WordPress Plugin

スプレッドシートのセルを記事内に埋め込み、スプレッドシートを更新するだけで全記事を自動更新できるWordPressプラグインです。

## 特徴

- 📊 **スプレッドシート連携**: Google Sheetsのセルを記事内に直接参照
- 🔄 **自動更新**: スプレッドシートを更新すれば全記事が自動的に更新
- ⚡ **高速表示**: キャッシュ機能でページ表示速度を維持
- 🎯 **簡単な記法**: `{{gs:A1}}` または `[gs_cell]A1[/gs_cell]`
- 📅 **スケジュール更新**: 1時間ごと、毎日、週1回など自動更新設定
- 🛠️ **管理画面**: 使用状況の確認、手動更新、キャッシュ管理

## 使用例

### 年次更新の自動化
```
今年は{{gs:A1}}の目標を達成しました！
```

スプレッドシートのA1セルを「2025年」→「2026年」に変更すれば、全記事が自動更新！

### 価格情報の一括管理
```
価格は[gs_cell format="currency"]B2[/gs_cell]です
```

スプレッドシートで価格を管理し、変更すれば全ページの価格が自動更新！

## インストール

1. このプラグインフォルダを `/wp-content/plugins/` ディレクトリにアップロード
2. WordPressの管理画面から「プラグイン」→「GS Dynamic Content」を有効化
3. 「GS Dynamic」メニューから設定を行う

## 初期設定

### 1. Google Sheets API の設定

1. [Google Cloud Console](https://console.cloud.google.com/apis/credentials) にアクセス
2. 新しいプロジェクトを作成（または既存のプロジェクトを選択）
3. 「APIとサービス」→「ライブラリ」から「Google Sheets API」を検索して有効化
4. 「認証情報」→「認証情報を作成」→「APIキー」を選択
5. 作成されたAPIキーをコピー

### 2. スプレッドシートの準備

1. Google Sheetsでスプレッドシートを作成
2. 共有設定を「リンクを知っている全員」に変更
3. URLから**スプレッドシートID**を取得
   - URL例: `https://docs.google.com/spreadsheets/d/`**`1ABC...XYZ`**`/edit`
   - `1ABC...XYZ` の部分がスプレッドシートID

### 3. プラグイン設定

1. WordPress管理画面の「GS Dynamic」→「設定」へ移動
2. **APIキー**と**スプレッドシートID**を入力
3. 「接続テスト」ボタンで接続を確認
4. キャッシュ設定と自動更新設定を調整
5. 「設定を保存」

## 使い方

### 基本的な記法

#### 方法1: `{{gs:セル}}` 形式（推奨）

```
今年は{{gs:A1}}です
価格は{{gs:B2}}円
営業時間：{{gs:Sheet1!C3}}
```

#### 方法2: ショートコード形式

```
[gs_cell]A1[/gs_cell]
[gs_cell sheet="Sheet1"]A1[/gs_cell]
```

### シート名の指定

```
{{gs:Sheet1!A1}}
{{gs:価格表!B2}}

[gs_cell sheet="Sheet1"]A1[/gs_cell]
```

### 名前参照（行名.列名）

セル番地の代わりに「行名.列名」で指定できます。
**1行目を列見出し、A列を行見出し**として使っているシートで有効です。

```
{{gs:消費者金融!プロミス.審査時間}}
{{gs:プロミス.審査時間}}   ← デフォルトタブの場合
```

| A | B | C |
|---|---|---|
| **サービス名** | **審査時間** | **金利** |
| プロミス | 最短3分 | 4.5%〜17.8% |
| アコム | 最短20分 | 3.0%〜18.0% |

上の表なら `{{gs:プロミス.審査時間}}` → 「最短3分」が表示されます。

- 行の追加・並べ替えをしても参照が壊れないのがメリットです
- 見出しは前後の空白を除いた完全一致で照合されます
- 該当する行名・列名が見つからない場合はデフォルト値（未指定なら空）になります

### デフォルト値の設定

```
[gs_cell default="データなし"]A1[/gs_cell]
```

### フォーマットオプション

```
<!-- 数値のカンマ区切り -->
[gs_cell format="number"]A1[/gs_cell]

<!-- 通貨形式（¥記号付き） -->
[gs_cell format="currency"]B2[/gs_cell]

<!-- 日付形式 -->
[gs_cell format="date"]C3[/gs_cell]

<!-- 日時形式 -->
[gs_cell format="datetime"]D4[/gs_cell]
```

### 範囲をテーブルで表示

```
[gs_range header="true"]A1:C10[/gs_range]
[gs_range class="my-custom-table"]A1:D20[/gs_range]
```

## 実用例

|---|---|


**スプレッドシート:**

|--------|------|

## よくある質問

### Q: スプレッドシートを更新したのに記事に反映されません

A: キャッシュが有効になっています。以下の方法で更新できます：
- 管理画面の「今すぐ更新」ボタンをクリック
- キャッシュ有効期間が経過するまで待つ
- 「キャッシュをクリア」ボタンをクリック

### Q: プライベートなスプレッドシートは使えますか？

A: 現在のバージョンはAPIキー方式のため、「リンクを知っている全員」に共有設定したスプレッドシートのみ対応しています。

### Q: 複数のスプレッドシートを使えますか？

A: 現在は1つのスプレッドシートのみ対応していますが、複数シート（タブ）の利用は可能です。
例: `{{gs:Sheet1!A1}}`、`{{gs:Sheet2!B2}}`

### Q: APIリクエスト制限はありますか？

A: Google Sheets APIには1日あたりのクエリ制限があります。キャッシュ機能を活用することで、APIリクエスト数を削減できます。

### Q: セルの値が表示されません

A: 以下を確認してください：
- APIキーが正しく設定されているか
- スプレッドシートIDが正しいか
- スプレッドシートが「リンクを知っている全員」に共有されているか
- Google Sheets APIが有効化されているか
- セル参照（A1など）が正しいか

## セキュリティについて

- APIキーは適切に管理してください
- スプレッドシートの共有範囲を適切に設定してください
- 機密情報をスプレッドシートに保存する場合は注意してください
